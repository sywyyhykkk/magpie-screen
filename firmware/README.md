# Magpie Screen 独立固件 0.3.28

适用硬件：Waveshare ESP32-S3-Touch-AMOLED-2.16，CO5300 480×480 AMOLED、QMI8658、CST92xx、AXP2101、16 MB Flash、8 MB OPI PSRAM。固件直接通过 Wi-Fi 读取 Magpie；日常无需运行网页预览或 USB 桥接。

## 首次构建与安装

安装 PlatformIO Core，然后在仓库根目录运行：

```sh
pio run -d firmware
pio run -d firmware -t upload
```

烧录前备份原厂整片 Flash。备份保存在本地被忽略的 `device-backups/`，不要提交含 Wi-Fi 或其他凭据的镜像。若串口被旧桥接或监视器占用，先停止相应进程。应用固件输出为 `firmware/.pio/build/liquid/firmware.bin`。

后续更新可在设备配置页上传该 `firmware.bin`；成功后自动重启。不要上传 bootloader、分区表或整片备份。分区变动、首次安装或恢复设备时使用 USB。

OTA 期间开发板会保持亮屏，显示固件接收进度、校验和重启状态；失败时显示提示 6 秒后返回原页面。配置页同时显示上传进度，传输达到 100% 后仍会等待设备校验确认。第三方上传器可通过 `X-Firmware-Size` 请求头提供应用文件字节数；未提供时屏幕显示已写入 KB。进度页面由接收更新的固件绘制，因此从 0.3.14 升级时，开发板的新进度页面会在下次 OTA 才显示。

## 配网与配置

1. 首次无 Wi-Fi 凭据时自动开启临时热点；随时长按右侧 GPIO18 键 3 秒也可开启。屏幕显示热点名、密码、配置访问码和地址。
2. 连接热点后访问 [192.168.4.1/config](http://192.168.4.1/config)；已联网时访问 `http://设备IP/config` 或 [magpie-screen.local/config](http://magpie-screen.local/config)。热点持续 10 分钟。
3. 输入配置访问码。成功认证后，同一浏览器、同一访问地址会记住访问码；点击“忘记此浏览器的访问码”可清除。已联网时页面显示当前 Wi-Fi，点击“切换 Wi-Fi”可修改网络。点击“扫描 Wi-Fi”，从附近的 2.4 GHz 网络列表中选择，也可以直接手动输入名称（包括隐藏网络）。列表按信号强度排序，同名网络合并，最多显示 64 个；选择后填写密码，再点击“连接 Wi-Fi”。扫描不会自动切换网络，也不会覆盖正在输入的名称或密码；已联网时保持连接，未联网时扫描结束后恢复使用已保存凭据重连。
4. 在 Magpie 开启局域网共享，配置 `http://Magpie主机的局域网IP:3425`，并提供允许读取额度、用量和路由的 API Key。当前支持局域网 HTTP，不支持 HTTPS、回环地址或带路径的服务地址。
5. 保存连接后等待采集，点击“刷新数据”取得账号和额度窗口。指定选择不存在时显示未知，不替换成其他账号。

API Key 和 Wi-Fi 密码保存在设备 NVS，不通过配置接口回显；API Key 留空保留原密钥。设备页面还可设置液体黏性、水平校准偏移量、后台路由过滤、真实账号显示、USB/电池亮度与熄屏时间。页面选择由实体按键控制，保存配置不会切换当前页面。

「02 / 页面与液体」可分别选择液体主题色和第一页图标，默认自动跟随供应商，支持识别 `remote-magpie/claude` 等远程供应商名称。也可独立指定 Codex 黑白、Claude 橙色、Gemini 蓝色主题及对应图标；仅影响外观，账号与额度窗口仍按原选择读取。保存后立即生效，重启后保留。

“显示真实账号”默认关闭。开启后第二页使用接口提供的账号名称；没有可靠账号数据时保留编号。会话兼容模式通过同一会话和请求 ID 匹配账号，核对供应商或最终模型，仅为已完成请求的最后一次尝试标注账号；兼容路由模型前缀与用量供应商不同的情况（如 `openai` 与 `codex`）。账号名称只缓存在内存中，切换设置会清空路由缓存并重新采集。

### 地址、API Key 和访问码从哪里获取

| 配置项 | 获取位置 | 填写方式 |
| --- | --- | --- |
| 开发板配置页地址 | 长按开发板右侧 GPIO18 按键 3 秒，查看屏幕上的 IP 和配置地址 | 已联网时打开 `http://开发板IP/config`，也可尝试 `http://magpie-screen.local/config`；连接开发板临时热点时打开 `http://192.168.4.1/config` |
| 配置访问码 | 同一次长按后，开发板屏幕显示的配置访问码 | 填入配置页的「配置访问码」，用于解锁开发板设置 |
| Magpie 地址 | 运行 Magpie 的电脑上，打开「设置 → 网络与共享 → 局域网」，开启「局域网共享」，复制「地址」 | 填入 `http://Magpie电脑的局域网IP:端口`，默认端口为 `3425`。复制结果若带 `/v1`，请去掉 `/v1`，只保留协议、主机和端口 |
| API Key | Magpie 左侧「网关 → 网关密钥」，点击对应密钥的「复制网关密钥」；没有密钥时使用「添加网关密钥」 | 粘贴到开发板「01 / Magpie 连接 → API Key」。确保该密钥允许读取额度、用量和路由；需要时开启对应密钥的「让这个密钥查看额度」 |
| Wi-Fi 网络名称和密码 | 路由器设置、已有联网设备保存的 Wi-Fi 信息，或向网络管理者获取 | 在「05 / Wi-Fi 配网」扫描选择或输入 2.4 GHz 网络名称，再输入该网络密码；隐藏网络手动输入名称 |

例如，Magpie 的局域网地址显示为 `http://192.168.1.10:3425/v1`，开发板的「Magpie 地址」应填 `http://192.168.1.10:3425`。这里使用运行 Magpie 的电脑 IP；开发板的 IP 用来打开开发板配置页。开发板和 Magpie 电脑需要能够通过局域网互访；如果 Magpie 配置了「允许的地址」，需包含开发板的 IP 或所在网段。

也可以在运行 Magpie 的 Mac 上通过「系统设置 → 网络 → 当前已连接的 Wi-Fi 或以太网 → 详细信息 → TCP/IP」查看电脑的局域网 IPv4 地址，再与 Magpie「设置 → 网络与共享」中的网关端口组合。不要填写 `localhost` 或 `127.0.0.1`：对开发板来说，它们指向开发板自身。电脑切换网络或 DHCP 地址变化后，需要重新核对 Magpie 地址。

「API Key」使用 Magpie 的网关密钥；「配置访问码」使用开发板屏幕上的访问码，两者用途不同。已保存 API Key 后输入框留空可保留原值，页面不会回显密钥；更换时粘贴新的网关密钥并保存。

### 静置时液面倾斜的校准

开发板立放静置后，如果液面仍有倾斜，可以在 `/config` 的「02 / 页面与液体 → 水平校准偏移量」中微调。水平基准来自 QMI8658 加速度计测得的屏幕平面重力方向；面向屏幕，以三个实体按钮所在边的位置区分朝上、朝右、朝下、朝左。不同放置方向可能需要不同的补偿角度，因此四项分别保存。

1. 将开发板立放在平整、稳定的表面，先保持四项为默认的 0°。
2. 让三个按钮朝上，等待液面停止晃动，再调整「三个按钮朝上」的角度并保存。正值使液面相对屏幕顺时针偏转，负值使其逆时针偏转。
3. 依次让按钮朝右、朝下、朝左，每个方向静置后调整对应项，最后转回各方向检查效果。屏幕朝上平躺时，屏幕平面的重力分量不足，算法会保持上次方向，不适合用来校准。

角度范围为 −180°～+180°，步进 0.1°，设为 0° 表示该方向不增加角度补偿。接近某个放置方向时使用对应值，旋转途中平滑过渡。该设置影响液体的重力方向、晃动响应和页面自动翻正判断，不改变额度数值、液体体积或最大液面高度，也不会将文字连续旋转相同角度。保存后立即生效，并保存在当前开发板，重启后保留。

## Wi-Fi 诊断

配网后最多等待 30 秒；遇到断连事件或超时，配置页显示“连接失败”、原因与芯片错误码，不再一直显示“连接中”。连接恢复并取得 IP 后自动清除错误。认证或握手失败不一定等于密码错误，也可能由信号、路由器访问限制或加密兼容性引起。

USB 串口（115200）输出 `wifi_event` JSON，记录开始连接、关联热点、取得／丢失 IP、断连和超时；`reason` / `reasonName` 保留 ESP32 原始原因，日志不输出 Wi-Fi 密码、API Key 或访问码。状态 JSON 与 `/api/status` 同时提供 `wifiError`、`wifiReason`、`wifiReasonName` 和 `wifiStatus`。

仅 USB 支持以下诊断命令，每条后跟换行：

```json
{"op":"wifi_scan"}
{"op":"wifi_retry"}
```

`wifi_scan` 异步扫描开发板可见的 2.4 GHz 热点，输出 `wifi_scan` JSON：`count` 是总数，`matches` 仅包含与已保存 SSID 同名的热点及其 RSSI、信道、认证类型／名称、最低安全要求是否满足和 BSSID；负数表示扫描失败，`error` 记录扫描错误。诊断扫描期间会暂时断开 Wi-Fi 并暂停自动重连，结束后恢复原重连设置并用已保存凭据连接。`wifi_retry` 使用已保存的凭据重新连接，不改写配置，也不回显密码。

### Wi-Fi 兼容模式

固件默认要求 WPA2-Personal（开放网络不受此门槛影响）。某些路由器不支持 WPA2 加密、仅支持旧版 WPA-Personal；即使已开启 2.4 GHz、信号正常且密码正确，也可能被连接筛选器排除并返回 `201 / NO_AP_FOUND`。成功扫描后，若同名热点均低于当前最低门槛，配置页会提示加密方式不匹配。

遇到这种情况，可在 `/config` 的「05 / Wi-Fi 配网」勾选「是否开启兼容模式」，点击「保存设置到开发板」。无法联网时，长按右侧 GPIO18 键 3 秒开启临时热点，再通过热点进入配置页。开启后允许 WPA-Personal，使用已保存的 Wi-Fi 名称和密码自动重新连接；无需修改路由器。设置保存在本开发板，重启后保留；取消勾选并保存后恢复 WPA2 门槛。也可先开启并保存，再填写新网络并点击「连接 Wi-Fi」。

WPA 安全性较低，建议仅在需要连接这类网络时开启。兼容模式不增加 5 GHz 或 WEP 支持。USB 状态日志的 `wifiCompatibility` 表示当前开关值，扫描结果的 `minimumAuth` 和 `meetsMinimumAuth` 按当前模式计算。

## 三页与按键

面向屏幕、USB 在下方时，顶部按键从左到右：

| 按键 | 短按 | 长按 |
| --- | --- | --- |
| BOOT / GPIO0 | 松开后进入液体余量 | USB 接入时长按 3 秒进入充电模式；上电按住仍进入下载模式 |
| PWR / AXP2101 | 实时路由 | 保留 PMU 关机行为 |
| GPIO18 | 今日概览 | 3 秒开启配置提示和临时热点 |

熄屏后的首次短按只唤醒。触摸和明显移动也会唤醒。内容在旋转停稳后按 90° 翻正，使用 420 ms 过渡；液面独立跟随重力。

- **液体余量**：供应商图标、剩余比例、额度窗口。灰度抗锯齿文字与同源图片素材；窗口说明保持单行，分隔点两侧等距。
- **实时路由**：来源、喜鹊、最多四个实际尝试目的地。只在新请求、尝试、响应和完成时播放一次动画；首次连接和重连不重播历史。所有请求完成且连续 10 秒无新路由活动后清空目的地，返回等待状态；未完成请求继续显示，重复快照不会重置计时或恢复已清空记录。
- **今日概览**：顶部显示电池图标和当前电量百分比，充电时显示绿色闪电标记，低于等于 10% 时以橙色提示，未检测到电池或读数无效时显示 `--%`。含缓存 Token 总量、输入/输出/缓存、请求数和成功率、USD 费用估算、缓存命中率、输出速度及供应商分布。超过三家时保留前两家，其余合并。

清空路由图仅影响显示，不删除 Magpie 的会话或请求历史。断网时未超时的数据保留；请求尚未完成时不会仅因轮询失败被判定完成。

第二页喜鹊沿实际连线直线滑动：客户端与 Magpie 之间保持水平，Magpie 与目的地之间按对应行的位置直线往返。同一请求各段依次播放，到达 Magpie 后停留 500 ms；不同请求可同时飞行。同方向、同目的地的喜鹊起飞至少错开 240 ms，避免轮询批量到达时完全重叠。事件批次和动画队列最多保留 64 段；未显示的目的地不借用其它行播放，动画仍只由真实状态变化触发。

## 充电模式

USB 接入时可手动进入独立的充电显示页面。

| 操作或状态 | 行为 |
| --- | --- |
| 长按第一个键（BOOT / GPIO0）3 秒 | 进入充电模式；熄屏时可继续长按，先唤醒再进入 |
| 松开进入时的按键 | 保持充电模式 |
| 页面显示 | 黑底中央仅显示电池百分比，例如 `80%`，不显示液体、图标或其它文字 |
| 亮度与熄屏 | 亮屏时固定 20% 亮度，进入后 30 秒无触摸自动熄屏；此计时独立于普通页面的熄屏时间及 USB 常亮设置 |
| 点击屏幕 | 唤醒并显示电池百分比，保持充电模式；亮屏时触摸也会重新计时 30 秒 |
| 按任意实体按键 | 无论亮屏或熄屏，均退出并点亮进入前的正常页面，该次按键不同时切页或开启配网热点 |
| 拔掉 USB | 收到 PMU 拔出事件并确认 USB 供电已断开后，自动退出并恢复正常电池显示策略 |
| 移动或业务数据更新 | 保持充电模式，不唤醒屏幕，也不重置 30 秒熄屏计时 |
| 无电池或电量读数无效 | 显示 `--%` |
| 电量达到 100% | 亮屏时显示 `100%`，保持充电模式和 30 秒熄屏规则 |
| 重启 | 恢复正常页面，充电模式不保存 |

退出后恢复对应 USB / 电池电源的亮度与熄屏设置，并重新计算空闲时间。充电模式不调整 PMU 的充电电流与电压；仅电池供电时无法进入。BOOT 上电按住进入下载模式、PWR 长按关机的硬件行为仍保留。

AXP2101 的 USB 插入、拔出和 PWR 按键事件统一处理：主循环每 50 ms 通过 I2C 读取事件标志，处理 USB 事件时核对当前供电状态。USB 插入会更新供电状态与显示策略，充电模式仍由长按第一个键手动进入。拔出后在该轮循环恢复正常页面及电池亮度；实际响应时间还受主循环执行耗时影响。电池百分比和电压每秒刷新，同时核对供电状态。此机制读取 PMU 的事件寄存器，不依赖 ESP32 GPIO 中断回调。

## 采集与兼容范围

| 状态 | 额度 | 今日用量 | 路由 |
| --- | --- | --- | --- |
| USB | 10 秒 | 15 秒 | 1 秒 |
| 电池亮屏 | 30 秒 | 30 秒 | 30 秒 |
| 电池熄屏 | 60 秒 | 60 秒 | 60 秒 |

网络请求在独立任务串行执行，上游响应慢时实际间隔会延长。优先读取 trace；若接口返回 403，回退到会话模式。会话模式约每 10 秒从当日最近 100 条请求发现最多四个会话，读取每个会话最新路由。新会话可能在首次请求完成后才被发现；短请求可能跨过中间状态，因此动画频率不等于实际调用频率。

## 电源与绘制

USB 默认亮度 70%，无活动 5 分钟熄屏、提前 30 秒调暗；电池默认亮度 40%，无活动 30 秒调暗、2 分钟熄屏。亮度范围 10–255，熄屏时间范围 30–3600 秒。亮度预览持续 5 秒，保存后长期生效。

USB 可开启常亮或新业务活动唤醒；电池模式的数据更新不唤醒屏幕。重复数据、心跳和液体余波不算用户活动。OLED 长期高亮显示固定内容有残影风险，配置页有常亮提示。

无电池时不显示虚假电量。电池低于等于 10% 时限制亮度；电池供电且电压持续 30 秒低于 3300 mV 时关机。固件保留 PMU 现有充电电流与电压配置。

静止时停止重绘，FPS 为 0 属于正常行为。运动时帧率上限 60 FPS。UI 覆盖层使用约 675 KiB PSRAM，按屏幕方向绘制并记录每行已绘制区间，只在内容变化时重绘；每帧合成只读取含 UI 的行。传输使用双 480×24 DMA 缓冲。液面按 1/4 像素深度查表并做 1 像素抗锯齿，完全在液面上方或深处的行直接整行填充。实机运动帧率应按当前固件和硬件测量。

液体（`src/liquid.h`）在重力坐标系中模拟：整体倾角模态加上贴合实际墙间弦长的 32 阶驻波，频率遵循水波色散关系（深浅、弦长、重力分量都会影响节奏，短波更快），黏性同时控制整体跟随与按波数平方衰减。转动时墙面推动液体产生过冲，快速旋转出现离心凹面，竖直颠簸从两侧墙面激起波纹，额度变化在液面中央溅起水滴。液面高度每帧按面积精确求解，波动不改变体积。加速度计以约 100 Hz 独立于渲染采样，经自适应滤波后驱动约 4 ms 一步的物理计算。陀螺仪（仅亮屏时开启）用来区分真实转动和左右晃动：晃动只改变等效重力方向，激起与晃动幅度相称的波浪，不会被误当成高速旋转。
