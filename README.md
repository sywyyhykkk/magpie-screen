# Magpie Screen

用于 Magpie 路由与服务状态的本地屏幕预览工具。Vue 3 + TypeScript 渲染 480×480 方形设计画布，轻量 Node 代理只读采集本机 Magpie 数据。

## 安装与运行

需要 Node.js 22.18 或更新版本。

```sh
npm ci --registry=https://registry.npmjs.org
npm run build
npm start
```

打开 http://127.0.0.1:4173。服务仅监听回环地址。前台运行时按 Ctrl-C 停止。开发模式使用 `npm run dev`，启动前应先停止占用同一端口的服务。

运行测试：

```sh
npm test
```

## 预览功能

- **模拟模式**：闲置、未完成、成功、失败、空数据和离线场景；可配置 1–4 个并发请求及 1–4 个目的地，手动播放一次模拟事件。
- **真实模式**：发现或手动选择会话、查看全部会话活动、过滤辅助调用，以及暂停和重连。
- **视图**：路由动画、用量与供应商、数据概览。数据适配器和画面组件独立，可分别扩展。

## 路由与动画

目的地仅来自实际尝试记录。同一账号的不同模型分行，并发请求保留独立事件身份；活跃目的地优先显示，更多记录在控制台列出。

动画由监控到的状态变化触发：

1. 新请求：客户端飞向 Magpie。
2. 新尝试：Magpie 飞向实际目的地。
3. 首次响应或尝试结束：目的地飞回 Magpie。
4. 请求结束：Magpie 飞回客户端。

每个事件只播放一次。等待期间保持静止，首次连接、重连和会话切换只同步基线，不重放历史。动画不表示生成进度，也不逐包重现网络传输。

## Magpie 接口

上游地址固定为 http://127.0.0.1:3425。代理只执行读取操作，不调用模型接口。

| 接口                                                   | 用途                      |
| ------------------------------------------------------ | ------------------------- |
| `GET /api/hello`                                       | 网关连接状态              |
| `GET /v1/magpie/usage?period=today`                    | 今日用量与计时汇总        |
| `GET /v1/magpie/usage/requests?period=today&limit=100` | 从近期 Codex 请求发现会话 |
| `GET /v1/magpie/trace?after=<seq>&wait=1`              | 增量路由事件              |
| `GET /v1/magpie/route?session=...`                     | 单会话最新路由            |

trace 接口在 `wait` 非空时固定等待最多 25 秒，代理超时为 30 秒。客户端按请求 ID 合并增量、移除过期记录，并在网关进程或序列变化时重置。会话发现仅覆盖近期记录，不是完整会话目录。

`done:false` 只表示未完成；已完成的 HTTP 2xx 请求显示成功，记录的错误显示失败。无路由数据与接口不可达分别显示。

账号默认匿名，可通过本机开关显示 Magpie 提供的账号名称。账号映射和会话标识只在内存中处理。代理排除请求正文、提示词、文件路径、原始错误文本及原始账号标识；本地配置与运行产物不纳入 Git。

## 用量与数据概览

用量页显示输入加输出 Token、请求数、费用估算、缓存读取和供应商分布；数据概览页单独显示包含缓存的 Token 总量、请求成功率、重试后成功数、缓存命中率、输出速度与平均首字耗时。两页读取今日全部来源，每 15 秒刷新，与路由会话选择独立。

数据概览的 Token 总量为输入、输出、缓存读取与缓存写入之和。缓存命中率为缓存读取占提示词总量（输入加缓存读取、缓存写入）的比例。输出速度按有效计时的输出 Token 总数除以总输出时长计算，并显示样本数；平均首字耗时使用首字计时总和与对应样本数。只有速度下限时使用“≥”标识；同时有两类样本时，优先展示样本更多的一类。

费用为已计价 USD 估算，不代表账单或剩余额度，未计价调用单独提示。缺失数据和无有效计时显示“—”；没有调用时显示零，接口不可达时不填入模拟数据。供应商汇总不包含账号、会话、文件路径或上游自定义展示文本。

## 结构与显示设备

- `server.mjs`：本地采集与响应字段过滤。
- `src/types.ts`：屏幕状态与事件映射。
- `src/RouteGraph.vue`：目的地和有限次事件动画。
- `src/RouteScreen.vue`：屏幕展示。
- `src/UsageScreen.vue`：用量与供应商。
- `src/OverviewScreen.vue`：数据概览。
- `src/App.vue`：预览控制和连接生命周期。

Web 画布用于界面设计，不是可直接烧录的固件。原生显示渲染器与 BLE/USB 传输属于独立适配层；设备可以接收精简状态变化并在本地播放动画，无需连续传输整帧。实际分辨率、驱动和硬件支持取决于目标设备。
